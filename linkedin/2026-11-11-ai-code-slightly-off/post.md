After a hundred pull requests from a teammate, you know their code without checking the name.

You know their habits and how they lay things out. So you don't read the details. You read what task they're solving and why. And you get a gut feeling: something in this pull request is off, maybe it solves a different task, and you sense it before you can explain it.

Agent-written code throws that off, for now. It works, but it's full of small things no teammate would write. The details pull your attention, and your gut gets slower.

I don't think that's a problem. It's a trade-off. Agents rarely get syntax, naming or parameters wrong, so you can review one level above that. The price is a code style you're not used to yet.

It's a transition. We got used to how our teammates write. Now we get used to how agents write.
