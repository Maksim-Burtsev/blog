I don’t read pull request descriptions anymore.

Agents write essays. Ten paragraphs, low density, the point buried somewhere in the middle. For a task I set myself, none of it is news: I already said what I want.

What I need is to see it work. So the agent records a demo: before, after, and the corner cases. One minute, and I know.

A critical technical change gets a diagram. A small one gets a single line.

Tests are the floor, not the review. Nothing red merges.

And the code? I read it anyway. Every pull request, whatever its size.
