Every feed tells me how much faster we ship with agents: thousands of pull requests a month (sometimes by one person), agent factories, almost all code written by agents.

Yet I can't name one app I use every day that got better in the last six months. Not the AI ones. YouTube, LinkedIn, Instagram, Gmail, WhatsApp, Telegram and the rest.

Some added dozens of features and turned into superapps. The core job works the same as six months ago, and the rest just clutters the screen.

Some changed nothing. The few A/B tests I got into were a surprise, and not a good one: worse UX, nothing new, sometimes just a worse design.

Most added AI for its own sake. At best nobody uses it. At worst it gets in the way: a support chat where an AI assistant and a human answer you in the same thread and talk over each other.

New apps show up every week. The ones we already use didn't get better.

So where does all that work go?
