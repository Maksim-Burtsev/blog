I gave my coding agents a reviewer that doesn't only find bugs. It reviews architecture, based on 30 classic books on software engineering.

Agents love to create 10,000-line files. They don't really care about your project's architecture or where the code should go. So a codebase written by AI is hard to navigate: nothing is where you'd expect it to be.

For code quality, you have strict linters and type checkers. Architecture was always the hard part. This skill is my attempt to help with it. Maybe it doesn't solve it completely, but it helps. 

It finds bugs as well as Claude Code's built-in code review. On top of that, it reviews the code's architecture against 78 principles distilled from those books. And it takes about the same tokens and time.

Agents can now work for hours or even days on their own. But the more autonomy they get, the more a bad design decision costs. It gets worse with every PR: the agents get lost in their own code, slow down and start breaking things.

The picture is the whole shelf. You've probably read a few of these.

It's called Punchcard, and it's open source. Link in the first comment.
